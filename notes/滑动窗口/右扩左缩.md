# 右扩左缩

> 滑动窗口:同向双指针的另一支——快慢指针压「元素」(原地写),这里压
> 「窗口统计量」(和/计数,一个变量随进出窗 O(1) 增减)。r 只扩不缩、
> l 只缩不扩,方向都不回头。
> 面试经典 150 题:209 · 同一子技巧的新题往对应小节追加
> 后访:3 无重复字符的最长子串(镜像:求最长=不可行才缩左)、
>   76 最小覆盖子串(统计量升级成带计数的覆盖)

## 框架总览(先看这节)

```
[ 0 .. l-1 已吐出 | l ===== r 窗口(统计量 sum) | r+1 .. n-1 未进 ]
                     ↑l 只往右(吐货)        ↑r 只往右(进货)
```

- 三行骨架(求最短型):`r 进货 sum+=nums[r]` → `可行(sum>=target)时:
  先收长度 r-l+1,再 l 吐货 sum-=nums[l++]`,吐到不可行为止;
- 每个元素至多进窗一次、出窗一次 ⇒ 均摊 O(n)(与快慢指针同款「每格只走
  一遍」的账,n 步进货 + 至多 n 步吐货);
- 题目变的是三个自由度:**统计量是什么**(和/计数/字符集)、**可行判据**
  (`>=target` / 无重复 / 全覆盖)、**求最短还是最长**(可行时缩=求最短,
  不可行时缩=求最长,3 的镜像);

| 题 | 统计量 | 可行判据 | 收缩时机 | 返回 |
|---|---|---|---|---|
| 209 最短子数组 | 窗口和 sum | sum >= target | 可行即缩(求最短) | 最短长度或 0 |

## 209. 长度最小的子数组(中等)—— 裸模板(求最短型)

**题意**:正整数数组与正整数 target,和 >= target 的最短连续子数组长度,
无解返回 0。

**怎么想到的**:正数送单调性(固定右端,左端越左和越大)⇒ 每个 r 的
「最短可行左端」L(r) 随 r 只右不移 ⇒ 双指针同向单程。全对暴力 O(n^2) 与
它的差,就是「l 不回头」省下的重复求和——窗口和用 sum 变量进出窗各 O(1)
维护,窗内不再重算。

```cpp
int ans = n + 1, sum = 0;
for (int r = 0, l = 0; r < n; r++)
{
    sum += nums[r];
    while (sum >= target)
    {
        ans = min(ans, r - l + 1);   // 先收:此刻还可行
        sum -= nums[l++];            // 再吐:while 不是 if
    }
}
return ans > n ? 0 : ans;
```

**坑**(详见 cpp 头注,穷举 67251 + 随机 40000 例实证):
- if 代 while:同一右端吐不完,答案往大里错(判官示例1 输出 4 真 2);
  先缩后收:记到不可行窗上,往小里错(同标本输出 1)——两坑一上一下;
- 判据丢等号:>target 把恰好压线的最优窗全放走(示例2 真 1 错 2);
- 无解哨兵 n+1 不是 n:n 是合法答案(全数组恰好凑够,如 [1,1,1,1]/4);
  失败集恰=无解用例(示例3 [1]*8/11 输出 8);
- 自敲标本(2026-11-16 一遍过 AC):与参考版零语义级差异——右端叫 i、
  sum/ans/l 三声明并一行;判据带等号/先收后吐/哨兵 n+1/终检四件全对,
  坑1-4 家族一个没踩。转写版全池零错。

**进阶 O(n log n)**(解法二,cpp 内 Solution3):前缀和把「区间和>=target」
坍缩成两数比较 `pre[j] >= pre[i]+target`(167 同宗:有序数组两数比大小),
全正 ⇒ pre 严格递增 ⇒ 对每个 i 二分最小 j。本题它比 O(n) 慢,练的是件套;
判据右端 pre[i]+target 最大 2e9 贴 INT_MAX 的线(剩 7%),量级抬半档就得
long long;upper_bound 会把恰等命中放走,带 >= 配 lower_bound。

## 原理

- **正数是地基**:r 进 sum 只增、l 出 sum 只减,可行↔不可行单调过渡,
  l 才敢「不回头」。nums 一旦允许负数,单调性塌,整个框架失效(方向没
  了:进窗可能变小、吐货可能变大),得换前缀和+单调队列(862 同族)。
- **为什么最优必被记录**:对每个 r,收缩把 l 停在「以 r 为右端的最短可行
  左端」;最优解必以某个 r* 为右端 ⇒ r* 那轮必被收进 ans。
- **收缩 while 为什么不用下标守卫**:条件只读维护中的变量 sum,不访数组
  ——125/15 的「守卫在前」护的是下标访问(nums[l+1]),不访连守卫都省;
  停机由全正保证:吐到空窗 sum=0 < target(target>=1)。守卫护「访」,
  不访无越界可谈。
- **均摊账**:r 合计 n 步、l 合计至多 n 步,总 2n——「每元素进窗一次出窗
  一次」,单步代价被总步数摊平,循环嵌套不代表 O(n^2)(对照:嵌套 while
  不回头的才有这待遇,回头的如 15 内层对撞是每锚重启)。
