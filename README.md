# leetcode

LeetCode C++ 题解仓库,记录自己的leetcode解题之路。
按题号组织,一题一文件,持续更新。

## 目录结构

```
面试经典150题/    题解,按题单分目录
notes/            主题笔记,组织规则与索引见 notes/README.md
_模板.cpp         新题模板
```

## 说明

- 命名规范:`题号-题名.cpp`,题号补零至 4 位(如 `0027-移除元素.cpp`,保证文件名排序即题号排序)
- 每题的思路、复杂度与踩坑写在文件头部注释;跨题的主题性总结进 `notes/`

## 进度

持续更新中,完成记录见提交历史与文件列表。
