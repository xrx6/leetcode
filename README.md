# leetcode

一题一文件,文件名 `题号-题名.cpp`,如 `0001-两数之和.cpp`。
思路写在文件头部注释里,和代码待在一起。

## 交卷(10 秒)

在本文件夹右键 → Git Bash Here:

    git add -A
    git commit -m "0001 两数之和"
    git push

GitHub 主页的贡献图(绿格子)就是这个仓库的连续记录:**每颗格子 = 那天真的写了代码**。
月底翻 commit 列表,就是你的刷题账本。

## 绿格子一定亮的条件

commit 邮箱要和 GitHub 账号里已验证的邮箱一致(本机当前用 2663087669@qq.com)。
注册 GitHub 直接用这个邮箱;已有账号就去 Settings → Emails 添加并验证它。

## 建议 Public

题解仓库公开是求职常态,面试官能直接看到你的练习痕迹。想私密也行,自己的绿格子照样亮。
