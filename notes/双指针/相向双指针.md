# 相向双指针

> 首尾各一枚指针向中间对撞:比较需要「一对」,答案关于对称位置。
> 面试经典 150 题:125 / 167 / 11 · 同一子技巧的新题往对应小节追加(后访:15 三数之和=排序+外层定一枚再对撞)

## 框架总览(先看这节)

双指针家族三姿势,至此凑齐:

| 姿势 | 走法 | 分工 | 代表 |
|---|---|---|---|
| 同向(快慢) | fast 读 / slow 写,同向前进 | 读写分工,压实 | 27 / 26 / 80 / 151 |
| 相向 | 首尾对撞,中间相遇 | 左右配对分工 | 125 / 167 / 11 |
| 逆向 | 写指针从尾倒走 | 空位在尾,避免覆盖 | 88 |

- 相向的本质:**比较需要一对**。答案问的是「对称位置的关系」(首尾配对、两数凑定值、夹板盛水),一枚从头、一枚从尾,向中间靠拢,失配即假、相遇即终。
- 框架三件套:**跳过**(干扰不参与配对,各自跳各自的,守卫 `l<r` 在跳前)→ **归一**(比较前统一形态,如 tolower)→ **配对**(失配即假)。
- **对撞的三种任务**(125→167→11):验证(125:判据只有成/败,失配即宣判整题假,走满窗口)、搜索(167:判据带方向——sum 与 target 比大小,大了 `r--` 小了 `l++`,失配=宣判一侧端点出局;不变量升级为「唯一答案对恒在 [l,r]」,循环内必 return)、求最值(11:面积=短板×间距,每步先更新 ans 再淘汰短板——它配窗口内谁都超不过当前;窗口走空时 ans 即最优,不 return)。
- 不变量:`l ≤ r` 恒成立(守卫跳过维持:左跳最多停在与 r 相等处,右跳不会低于 l)⇒ l==r 时自己比自己必等,跳完不必再判一道。
- 复杂度骨架:l、r 各自单调不回头,合计移动 ≤ n ⇒ O(n);全程原地 ⇒ O(1)。
- 题目只换自由度:**跳什么**(干扰判据)、**怎么归一**(大小写/权重)、**配什么对**(相等/和为定值/夹板取短板)。

## 125. 验证回文串(简单)—— 裸模板+跳过干扰

**题意**:大写转小写、丢掉非字母数字后,串正反读一样则真。

**怎么想到**:回文的定义就是「首尾对称位置逐一相等」——定义自带指针方案:顺序扫描要回头,配对不必。两件事污染配对:非字母数字(不参与 ⇒ 撞上就跳)、大小写(同字符 ⇒ 比前归一)。

```cpp
class Solution {
public:
    bool isPalindrome(string s) {
        int n = s.size(), l = 0, r = n - 1;
        while (l < r) {
            while (l < r && !isalnum(s[l])) l++;   // 跳过干扰,守卫在前
            while (l < r && !isalnum(s[r])) r--;
            if (tolower(s[l]) != tolower(s[r]))    // 归一后再比
                return false;
            l++; r--;
        }
        return true;                               // 空串/全干扰天然真
    }
};
```

**坑**(细节与穷举实证见 `面试经典150题/0125-验证回文串.cpp`):
- **isalpha 误替 isalnum**:数字也是字母数字字符。最小反例 `"0P"`(判官经典):丢 '0' 剩 "P" 误 true,穷举池 265 例错 61。
- **不归大小写**:'A'≠'a',`"aA"` 误 false。tolower 对非字母原样返回,不必先 isalpha 分支。
- **跳过无守卫**:左跳跑出串尾、右跳成 r=-1,operator[] 无声越界读 UB(`"!!"` 即死;Python 转写响亮 IndexError 对照,0028 π 表开小同族)。只守一侧,另一侧照越界:右跳裸奔时 Python 负下标先悄悄绕回串尾,再往下才响。
- **跳完直接比是安全的**(未爆):守卫保证 l≤r,l==r 自比必等——是守卫救了这里,不是比较处的 if。

**解法二串册**:把「跳过+归一」前置成快慢指针滤芯(27 骨架换芯:收 isalnum、写 tolower),压出 [0,slow) 再半程对撞——见 `快慢指针.md` 表 125 行。151 压完要 resize 砍尾是因为要交整串,125 不交串:比较认 slow 不认 size(),那一刀天然免掉。

**自敲标本(2026-11-01,一遍过 AC)**:与参考版逐行同构——数字在编制、两侧归一、跳过守卫三处必爆全数保留。唯一差:不开 n 中间变量,`r` 直接收 `s.size()-1` 的无符号减法;n≥1 约束下安全,空串则 size_t 先回绕再转 int(主流平台得 −1,恰好无害)——**立刻收进 int 把回绕截在原地,留在无符号域进比较/更长运算才会飞**(语言参考·长度节同族)。自敲版以 Solution2 与参考版并存于 0125.cpp。

## 167. 两数之和 II - 输入有序数组(中等)—— 对撞搜索:失配给方向

**题意**:非递减数组里找两数和为 target,返回 1 起下标;只要常数空间。

**怎么想到**:题面三个题眼连读——有序+凑定值+常数空间。暴力每对都试,答案对的 index1 靠后时前面每个 i 白扫全程(自己先试 20/26 TLE)。有序给的单调性允许整列淘汰:sum>target 时 r 与窗口内任何 l' 配都 ≥ 当前和仍超(numbers[l']≥numbers[l])⇒ r 凑不出答案,r-- 出局;对称 sum<target 时 l++。每步至少废一枚端点 ⇒ O(n)。125 的对撞在「验证」(判据只有成/败,失配即假),167 判据带方向升级成「搜索」:失配不再宣判整题,而是宣判一侧端点出局——淘汰前先证「出局者凑不出答案」,与 392 贪心最早匹配的交换论证同宗。

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& numbers, int target) {
        int l=0, r=numbers.size()-1;          // 答案对恒在 [l,r]
        while(l<r)
        {
            int sum=numbers[l]+numbers[r];
            if(sum==target)
                return {l+1, r+1};             // 下标 1 起
            else if(sum>target)
                r--;                           // 大了:r 整列出局
            else
                l++;                           // 小了:l 出局
        }
        return {-1,-1};
    }
};
```

**坑**(细节与穷举实证见 `面试经典150题/0167-两数之和II-输入有序数组.cpp`):
- **方向移反**(大了 l++/小了 r--):最小反例 [-4,-4,-3]/-8 扑空,穷举池 88.5% 必爆;方向由「谁能把 sum 朝 target 拉」定。
- **自敲 WA 标本(坑5/6)**:判据拿单支 numbers[r] 比 target(该比**和**——搭档可为负/零,判官用例答案右支第一步就被出局);守卫用出界版 l<n&&r>=0(该用**窗口不空** l<r——放行 l==r 自配与 l>r 交叉反配,判官输出 [4,3]=元素对顺序反)。两坑分工:只修判据全对(松守卫单独未爆),只修守卫错数不减、乱序/自配全塌成扑空。
- **解二二分限右段**:全数组找会找到自己,[-4,-4]/-8 误报 [1,1];失败集恰好=答案是等值对的用例。
- **自敲 TLE 标本**:O(n^2) 没吃「有序」题眼(逻辑全对输在档位);顺带条件位 `i<n,c<=0` 逗号运算符静默丢左条件(语言参考·坑总集新行)。

## 11. 盛最多水的容器(中等)—— 对撞求最值:每步淘汰短板

**题意**:n 根竖线立在下标 0..n-1 上,任选两根与 x 轴围容器(不能倾斜),容量 = min(两板高) × 下标差,求最大容量。

**怎么想到**:面积公式自带两件事——水位由**短板**决定,宽度由下标差决定。暴力每对都量 O(n²)(n=1e5 约 5e9 次)必超,但「短板决定水位」给了整列淘汰的理由:首尾对撞,先用当前窗口更新 ans;设 height[l] < height[r],任何留下 l、把 r 往左收的对 (l,r') 都有 min(height[l],height[r']) ≤ height[l]、宽度更小 ⇒ 面积 ≤ 当前面积——短板 l 配窗口内谁都超不过当前,它不可能出现在更优解里,l++ 整列出局。长板必须留着:它可能等到更高的新板把水位抬起来([1,5,100]:留 100 等到 5,5×1=5 > 1×2=2)。每步至少废一枚端点,合计 ≤ n-1 步。

167 的「失配淘汰一侧」在这里改头换面成「每步先记当前、再淘汰必输的一侧」:没有 return,窗口走空时 ans 就是最优——对撞的第三种任务「求最值」。

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int n = height.size();
        int l = 0, r = n - 1, ans = 0;
        while (l < r)
        {
            ans = max(ans, min(height[l], height[r]) * (r - l));  // 面积=短板×间距
            if (height[l] < height[r])
                l++;                                               // 淘汰短板,不淘汰长板
            else
                r--;                                               // 等号收右也安全
        }
        return ans;
    }
};
```

**与 42 的关系**:42 的双指针版也移动较矮的一侧,动作相同,但论证不同源——42 证的是「矮侧的已知 max 就是真正的瓶颈」(另一侧 max 只会更大,故该位置水位已定),11 证的是「短板配窗口内谁都超不过当前面积」。动作同、论证各表,别把两题的证明互抄。

**坑**(细节与穷举实证见 `面试经典150题/0011-盛最多水的容器.cpp`):
- **水位取错**:高度是 min(短板),不是 max、更不是单边。[1,2] 的 max 版得 2(真值 1),穷举池(长度 2..6×高度 0..3,长度≥3 子池 5440 例)错 4753,87.4% 必爆级;恒取左/恒取右同样各有 48.2%/59.4% 的错。
- **淘汰长板**(方向反):最小正数反例 [1,3,3](错版 2≠3);[1,5,100] 错版 2≠5;判官示例真值 49,错版只有 8;池内 65.1% 必爆。与 167 的方向移反同族:淘汰错了对象——宽度只会变小,收长板时水位不升,面积只会小;只有收短板才可能让水位跳高。
- **宽度差一**:间距是 r-l,不是点数 r-l+1。[1,1] 真值 1、错版 2;池内 98.9% 必爆(全场最离谱的一项)。
- **每轮双收**:丢的是「换搭档」的中间态 (l,r-1)/(l+1,r)。[1,2,3,4] 真值 4(下标 1,3 的 2×2)、双收版 3;池内 56.1% 错。
- **未爆两条**:等号时收哪边、甚至两边同时收都安全(h[l]==h[r] 时两侧都是短板,含 l 或 r 的对面积 ≤ 当前,池内 0 错);while(l<=r) 的 l==r 自配面积恒为 0,白算一次无害——对照 167 的 l==r 自配必爆(那边是同一元素用两次,违反题面)。同一处守卫,题意不同,判罚两样。

## 原理

- **为什么 O(n)**:l 只增、r 只减,移动总数 ≤ n+1;每个字符至多被左右指针各碰一次。
- **为什么空串/全干扰返回真**:两枚指针(连同跳过)擦肩而过,全程没发生任何比较失败;「没有失配」就是回文定义对空串的退化(示例3)。
- **奇偶长度同一个收场**:奇数的中间格不配对——守卫让 l、r 相遇在同一格(l==r 自比必等)后 l++/r-- 自然分离退出;偶数则擦肩(l 越过 r)。两种都落同一个 `return true`,不需要奇偶分支。
- **每步淘汰为什么安全(167)**:sum>target 时,对窗口内一切 l<l'≤r-1 有 numbers[l']+numbers[r] ≥ numbers[l]+numbers[r] > target ⇒ r 在窗口内没有搭档;答案恒在窗口内 ⇒ 必不含 r ⇒ 弃 r 不亏。对称弃 l。答案对永不出局 ⇒ 窗口缩到答案对自身必命中,循环体内必 return,l<r 打不满——这是「搜索型对撞」的终止方式,与 125 「验证型」走满整个窗口收场不同。
- **O(n)(167)**:l 只增 r 只减,合计移动 ≤ n,每步一次加法——比 125 还省,连跳过内层循环都没有。
- **每步淘汰短板为什么安全(11)**:设 height[l] < height[r],窗口内任何留住 l 的对 (l,r') 都有 min(height[l],height[r']) ≤ height[l] 且宽度更小 ⇒ 面积 ≤ 当前面积。即短板 l 配窗口内谁都超不过当前:若最优解含 l,当前面积已 ≥ 最优(ans 已记录);否则 l 本就不在最优解——两种都说明弃 l 不亏。长板不能弃:它可能等到更高的新板把水位抬起来([1,5,100] 里的 5×1)。
- **O(n)(11)**:l 只增 r 只减,合计移动 ≤ n-1;每步一次 min 一次乘法,无内层循环,空间 O(1)。
