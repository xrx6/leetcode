# 逐列比较

> 多条串求「公共」的东西 ⇒ 按列对齐:同一列全票相同才前进,一票否决即停。
> 两个等价视角:纵向=按列投票(以第一条为参照),横向=按串折叠(滚动候选只缩不涨)。
> 面试经典 150 题:14 · 同一子技巧的新题往对应小节追加

## 14. 最长公共前缀(简单)

**题意**:字符串数组的最长公共前缀;不存在返回 ""。

**怎么想到的**:「公共前缀」= 每条串的第 0..k 格都相同——信息按**列**对齐,与行内
先后无关。两条路殊途同归:

- 纵向:第 j 列拿 strs[0][j] 当参照,列内全票相同才进第 j+1 列;有人不同或有人
  到头,当场收工;
- 横向(自敲版):候选从 strs[0] 出发,每来一条截到与它一致——公共性有一票否决,
  候选只会被截短、不会变长(LCP(a,b,c)=LCP(LCP(a,b),c),结合律保证折叠顺序无所谓)。

**代码**(横向折叠,自敲版骨架;两刀=长度刀+内容刀,缺一不可见坑):

```cpp
string s = strs[0];                                  // 滚动候选:只缩不涨
for (int i = 1; i < strs.size(); i++) {
    if (s.size() > strs[i].size())
        s.erase(strs[i].size(), s.size());           // 长度刀:候选不长于当前串
    for (int j = 0; j < strs[i].size() && j < s.size(); j++)
        if (s[j] != strs[i][j]) {
            s.erase(j, s.size());                    // 内容刀:失配格起全不要
            break;
        }
}
return s;
```

纵向参考版(以 strs[0] 为参照,不拷贝候选):

```cpp
for (int j = 0; j < strs[0].size(); j++)
    for (int i = 1; i < strs.size(); i++)
        if (j >= strs[i].size() || strs[i][j] != strs[0][j])
            return strs[0].substr(0, j);             // 列内不同 / 有人到头,一票否决
return strs[0];                                      // 每列全票通过:整条都是前缀
```

**坑**:
- 两刀缺一不可(0014 坑1):只有内容刀,"flow" vs "fl" 逐字全等、没有失配,候选
  截不短;只有长度刀,首格失配截不掉。一个管 min 长度,一个管失配点。
- erase 二参是「长度」且会**钳制**:erase(pos, s.size()) 实际效果=删到尾,恰好
  无害;把话说准的写法是一参数 erase(pos)(语言参考·string 删段)。
- 失配截断后没 break、靠 `j < s.size()` 每轮重求值退出:必然成立(s 长度恰变成
  j)但隐式,要求读者知道条件每轮重算;显式 break 一眼明白(0014 坑3)。
- 边界天然安全:空串让 `j < size()` 直接不进循环;约束 1≤n 保证 s=strs[0] 不越界。

**复杂度对比**:
- 横向折叠:O(S) 时间、O(L) 空间(候选副本);两刀各自 O(候选长),总量仍 O(S)
- 纵向逐列:O(S) 时间、O(1) 额外空间(以 strs[0] 为参照不拷贝);首列即否决的
  输入(如 "dog","racecar","car")第一轮就收工
- 排序首尾:O(nL·log n) 排序后只比字典序最小/最大两条——LCP(全部)=LCP(min,max)

## 原理

一票否决 ⇒ 单调收敛:候选前缀的长度随见过的串**单调不增**——这是「滚动变量」
家族(238 滚动乘积、42 滚动 rightMax)在字符串上的脸:跑一趟,答案变量只朝一个
方向收敛,无需回头。纵向=按列投票(第一条当参照),横向=按串投票(候选当靶子),
结合律 LCP(a,b,c)=LCP(LCP(a,b),c) 保证两种折叠等价——先跟谁比都一样,最短/
最先否决的那条说了算。排序性质是它的推论:字典序 min 和 max「夹住」了全体,任何
第三条串逐格落在两者之间,与全体一致的列必然与首尾两条一致。
