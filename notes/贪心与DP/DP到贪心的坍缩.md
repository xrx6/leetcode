# DP 到贪心的坍缩

> 框架总览:两者都是解「多步决策问题」的方法(每步的选择影响后续,问最值/可行性)。**DP = 带记忆的穷举**,天生正确但慢;**贪心 = 证明了「不用穷举」**,快但有前提。贪心常是 DP 发现自己 dp 表有特殊结构后的「瘦身版」。

## 定义

- **DP 三件事**:①切子问题(122 的 `dp[i][0/1]` = 第 i 天某状态的最大利润);②存答案,每个状态只算一次;③小推大(转移方程)。正确性来源:**转移里把所有选择都试了取最优**——聪明的穷举,没漏任何可能。
- **贪心**:不建表,从头到尾扫,每步只做一个「当前最优」的动作,不回头、不比较。正确性前提:**局部最优能推出全局最优(贪心选择性质)**,需要证明;错了不报错,答案悄悄错。

## 找零钱反例:贪心为什么会错

币值 {1,5,11} 凑 15:贪心「每次拿最大」= 11+1+1+1+1 共 5 枚;最优 5+5+5 共 3 枚。第一步拿 11 把后面逼进残局——**眼前最好的选择堵死了后面的路**。DP 的转移会同时试「拿/不拿 11」,所以不会被堵死。此型贪心是「砍树」:拿 11 = 扔掉「不拿 11」的整棵搜索树,结构不保证时,砍掉的可能恰有最优解。

## 区别一张表

| | DP | 贪心 |
|---|---|---|
| 每步 | 所有选择都试,取最优 | 只按规则走一条,不回头 |
| 正确性 | 穷举所有状态,天生正确 | 需证明「局部→全局」,错了不自知 |
| 速度 | 慢(状态数 × 转移代价) | 快,常 O(n) |
| 存什么 | 整张 dp 表(或滚动压维) | 一两个变量 |
| 适用 | 通用保底 | 仅有特定结构的问题 |

**本质分界**:DP 花时间买正确(多花的那重循环 = 不敢假设任何结构);贪心花证明换时间(敢扔循环 = 有人先证明了扔了不漏)。

## 联系:贪心 = DP 的瘦身(塌缩实录)

- **55 跳跃游戏**:`dp[i]` = 下标 i 是否可达,O(n²)。可达集合连成一片(去 j 的「最后一跳」缩短即可落途中任意格)→ dp 表必为 `[真…真假…假]`,**一条分界线** → 整表信息 = 边界在哪 → 塌缩成 `reach` 一个变量、一重循环。reach 是所有走法的并集边界,没丢任何路——**零风险压缩型贪心**。
- **45 跳跃游戏II**:`dp[i]` = 到 i 的最少跳数。「k 跳能到 i ⇒ k 跳能到任何更前的格」→ dp 非降 → 表是阶梯 `[0,1,1,2,2]` → 每级台阶 = 一跳覆盖的连续区间 → 塌缩成「层边界 end/farthest + 计数」。
- **122 买卖股票II**:状态机 `dp[天][持股]` 二维;不限次交易时坍缩成贪心 `Σ max(0, 相邻日差)`。
- **274 H指数**:同思想变体——f(h) = 被引 ≥h 的篇数单调不增,判定单调 → 排序后一次扫描/二分,不用每个 h 重数。
- **134 加油站**:候选集塌缩——暴力 = 每个起点各绕一圈 O(n²)。事实:从 A 出发死在 B ⇒ (A..B] 内任何起点也过不了 B(A 走到中途任一站时油量 ≥ 0,接管者身上只有 0,处处更穷)→ 一次失败淘汰一整段候选,起点只前进不回退,塌成一趟 O(n)。配第二事实 Σdiff 与起点无关:<0 直接 -1,≥0 必有解。diff 前缀和视角与 238 前缀积同族:答案 = 前缀和最低点的下一站。追问两记:① 凭什么不绕第二圈?死 ⟺ 折线跌破清零点、清零点 = 上次死处 → 死一次创一次新低,最后一死处即前缀和全程最低点;环回段油量 = total + (P[j]−最低点),两项各自 ≥ 0,纸面不等式替掉模拟(贪心 = 用证明换模拟的标本)。② start 全程只是「候选人」:段淘汰管「除了它还能是谁」,total 终审管「连它都不行吗」——total<0 时最优候选恰死在整圈最后一步(离开 start-1 站时油量 = total);更晚的 s′ 若行则 start 必行(到达 s′ 时的盈余此后永久保持),故更晚站连测都不用测。

一句话:**DP = 我都算过所以我知道;贪心 = 我证明过不用算所以敢直接选**。贪心能做的 DP 都能做(顶多慢),反之不成立。

## 两类贪心,风险不同

- **压表型(零风险)**:如 55/45——贪心量是所有走法的**聚合**(并集边界/层边界),无损压缩 DP,证明连通性/单调性即可。
- **砍树型(有风险)**:如找零钱——每步真的**丢弃**选择分支,需证明「砍掉的树里没有更优解」,难得多。
- **候选淘汰型(零风险)**:如 134——砍掉的不是选择分支而是候选起点,且每段被砍前已有死因证明(段内接管者更穷,活不过同一段路),砍的全是死树。看到贪心题先问:它压表、砍树,还是淘汰候选?

## 实战流程

1. 能否一句话说出「每步做什么」的规则?说不出 → 直接 DP。
2. 说得出 → 找反例/想证明;有反例 → DP。
3. DP 状态定义得出、维数可控 → 保底解,先 AC。
4. 回头看 dp 表长什么样(分界线?阶梯?可合并的重复结构?)→ 有结构就塌缩成贪心,再 AC 一遍。
