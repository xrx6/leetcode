# 逆序双指针

> 写指针从后往前走:空位在尾部时,倒着填永远不会覆盖未处理的元素。
> 面试经典 150 题:88 · 同一子技巧的新题往对应小节追加

## 88. 合并两个有序数组(简单)

**题意**:nums1 尾部有 n 个空位,把有序的 nums2 归并进去。

**为什么从后往前**:空位在尾部,从后往前每次取两边**较大**者填入,写入位置 `k = i + j + 1` 恒大于 i,永远不会覆盖 nums1 未处理的元素 → 不用开额外数组,O(m+n) 原地完成。

```cpp
int i = m - 1;         // nums1 有效部分末尾
int j = n - 1;         // nums2 末尾
int k = m + n - 1;     // 写入位置
while (i >= 0 && j >= 0) {          // 注意 &&:比较需要两边都有元素
    if (nums1[i] > nums2[j]) nums1[k--] = nums1[i--];
    else                    nums1[k--] = nums2[j--];
}
while (j >= 0) nums1[k--] = nums2[j--];   // 只需善后 nums2!
```

**为什么 nums1 剩的不用管**:循环结束时若 nums1 有剩余,说明它们都比已填入的小,且位置天然正确;nums2 剩的还没进数组,必须搬。

**精简变体**:主循环只判 `while (j >= 0)`,判断写 `if (i >= 0 && nums1[i] > nums2[j])` —— 把「i 耗尽就搬 nums2」合进 else,连善后循环都省了。

**复杂度对比**:
- 拷贝 + sort:O((m+n)·log(m+n)),没利用「两个数组各自有序」
- 逆序双指针:O(m+n) 时间、O(1) 空间 ← 进阶要求
