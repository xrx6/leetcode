# 组合结构与换尾删除

> 框架总览:设计题(不问算法、问「造结构」)的读题法——题面划两栏:**它规定的**(语义/复杂度/返回值,必须满足)和**它没说的**(内部顺序/布局/选型,全是弹药)。380 的全部巧妙都藏在「没说的」一栏:题目要的是**集合**,顺序、住址全是自由,拿自由换性能。

## 380 O(1) 插入/删除/随机取

**题意**:实现集合,insert/remove/getRandom 全部平均 O(1),getRandom 等概率。

**怎么想到**(三步):

1. **单结构试错**:vector 尾插 O(1)、随机下标 O(1),按值删 O(n);unordered_set 增删 O(1) 但**无下标**,getRandom 做不了等概率。两者短板恰好互补。
2. **组合**:vector nums = 仓库(出「按位置」能力,支撑随机取);unordered_map pos(值→下标)= 登记簿(出「按值」能力,支撑 O(1) 定位)。
3. **换尾删除**:剩的硬骨头是「删中间格要 O(n) 挪」。让尾元素填进空位 + `pop_back`,两个 O(1)。中间删 O(n) 的代价全花在「维持顺序」上,而顺序题目根本不要——**用一次 O(1) 搬家替代 O(n) 的全体前移,乱序免费**。

**换尾删除五步**(删 val):①pos 查 val 得空位 idx;②尾元素 last 填进 `nums[idx]`;③`pos[last]=idx`(搬入者改登记,**必须在⑤前**——删尾元素本身时 last==val,先 erase 再赋值会把刚注销的键又插回来);④`pop_back`;⑤`pos.erase(val)`。

**为什么偏偏尾元素来填**:填洞要「搬来后旧地不产生新洞」。中间元素搬走,原地又是新洞,按下葫芦浮起瓢;尾元素的旧位置就是最后格,pop_back 连格带元素一起注销——**唯一零善后成本**的搬家(尾部删除免费是它的物理基础)。

**代码**:见 `面试经典150题/0380-O(1)时间插入删除和获取随机元素.cpp`。

**坑**:成员变量写进构造函数 = 局部变量;忘③则不变量破裂(延迟爆炸);unordered_set 单挑做不了 getRandom;`pos.count` 判存在、`pos[新键]` 写入才安全。

## 原理:不变量(账实一致)

两个结构在语言上毫无关系,靠一条**永远成立的约定**绑定:

> pos 的每个键都在 nums 里,且 pos[k] 就是 k 此刻在 nums 里的真实下标。

每个操作「动仓库必记账」= 保持不变量;bug 的本质都是打破它(忘③ = 登记簿与仓库对不上)。类(私有成员 + 成员函数)是这份纪律的守护者:外界只见「三个 O(1) 的集合」,碰不到内部两本账。

对照:55/45 的不变量(可达集合连续前缀/dp 阶梯)是题目送的,我们去**发现**;380 的是我们自己立规矩、自己去**维护**——发现结构 vs 发明结构。

## 复用信号

- 「按值 O(1) 删 + 不关心顺序」同时成立 → 换尾删除。
- 「既要按下标取、又要按值找」→ vector + 哈希 组合,各出一种能力。
