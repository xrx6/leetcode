# 主题笔记

> 这里只放**跨题的主题性总结**。单题的思路/复杂度/坑写在 `面试经典150题/xxxx.cpp` 头部注释里,不在这里重复。

## 组织规则

1. **一个算法主题一个文件夹**:`双指针/`,以后可能有 `滑动窗口/`、`二分查找/`……
2. **一个子技巧一个文件**,文件名 = 子技巧名(如 `快慢指针.md`)。新题先找现有小节追加,确属新技巧才建新文件。
3. 文件内部统一顺序:**框架总览 → 每题小节(题意 → 怎么想到 → 代码 → 坑)→ 原理 → 自测问题**。
4. 每篇文末保留「自测问题」,合上笔记自测。
