# 倒序扫描

> 问「最后一个/末尾」就别从左扫:信息在尾部 ⇒ 从右往左,起点就在答案门口。
> 统一骨架:先跳过尾部无效填充,再一路读,撞上下一个边界即停。
> 面试经典 150 题:58 / 151 · 同一子技巧的新题往对应小节追加

## 58. 最后一个单词的长度(简单)

**题意**:单词仅由字母组成、以空格分隔,前后可有多余空格,求最后一个单词的长度。

**怎么想到的**:要的是「最后」一个,而串的末端就是「最后」——从右端出发离答案最近。
正序扫必须走完整串才能确定谁是最后一个单词,还得一路记账词边界;倒序把问题缩成门口
两小步,词间多空格、前导空格全与它无关。

**代码**(两趟 while,标志位兼计数器):

```cpp
int i = s.size() - 1;
while (i >= 0 && s[i] == ' ') i--;      // 第一趟:跳过尾部空格
int len = 0;
while (i >= 0 && s[i] != ' ') {         // 第二趟:数最后一个单词
    len++; i--;
}
return len;
```

**坑**:
- 串尾可能全是空格(示例 2 末尾两个):不先跳过,第一格就是「边界」,直接数出 0。
- `i >= 0` 必须写在 `s[i]` 前面:靠 && 短路挡住 i=-1 的越界访问。
- 「进没进单词」不用 bool:`len > 0` 本身就是标志——计数器兼标志位。
  (自敲版用 l/c 两个变量,恒 c==l,是同一信息的两份拷贝,见 0058 坑3。)
- 悬空语句:自敲版 `else l++; c++;` 的 c++ 不在 else 里,缩进骗人;本题靠
  continue/break 的控制流恰好无害,详见 0058 坑2 与语言参考坑总集。

**复杂度对比**:
- split 全串切词取末尾:O(n) 时间、O(n) 空间,整串都要碰
- 倒序扫描:最坏 O(n)(全串一个单词/前导一大段空格),常态只碰「尾部空格+末单词」
  一小段;O(1) 空间 ← 时间同阶,赢在少走 + 不开辅助容器

## 151. 反转字符串中的单词(中等)—— 骨架的「不停版」

**题意**:单词顺序颠倒、词间单空格、无前后导空格。58 问「最后一个词」,走到第一个词就收工;
151 要「所有词倒着报」——同一副「跳空格 → 吃到词边界」的骨架,外面套层 while 别停,
从右往左收到的词天然就是倒序。

**代码**(O(n)/O(n);完整注释在 `面试经典150题/0151-*.cpp` 解法一;O(1) 进阶走 `翻转/三次翻转.md`):

```cpp
int i = s.size() - 1;
while (i >= 0) {
    while (i >= 0 && s[i] == ' ') i--;    // 跳词右侧空格:尾部/词间多余全在这消掉
    if (i < 0) break;                     // 跳完已出界:前导空格段不是「幽灵空词」
    int end = i;                          // 锚定词右端
    while (i >= 0 && s[i] != ' ') i--;    // 吃到词左端外一格
    ans += s.substr(i + 1, end - i);      // 收词
    ans += ' ';                           // 词后统一补,末尾一刀
}
ans.pop_back();                           // 多补的那一个空格
```

**坑**:
- 不写 `if (i < 0) break;`:前导空格段被当「空词」收进来,答案多一格尾空格——内层 while 的短路保的是「读」,外层 break 保的是「收」,两道岗各管一段。
- 词后统一补空格 ⇒ 末尾必多一个,pop_back 一刀(哑结点家族「统一动作+末尾一刀」)。

## 原理

答案锚定在串尾 ⇒ 起点即终点:扫描长度 = 尾部空白长 + 答案长,与串的前半段无关。
这是「读问题时先定位信息住在哪头」的一族——问末尾就倒着读(58),空位在尾就倒着写
(88 逆序双指针)。倒着读为的是**少走**(提前停),倒着写为的是**不覆盖**(写入位置
恒大于读取位置);方向相同,目的不同。0058 的自敲版(单 for + c 标志)与两趟 while
等价:continue 承担第一趟(跳尾部空格)、break 承担第二趟的终止(撞上左边界),
两段压在一个循环体里。151 把「问末尾」推广成「问整条的倒序」:起点仍在答案门口,
只是门口有一个词就报一个、报完接着往左走——58 是这骨架「收一个词就停」的特例,
边界从「串的左端」推广成「每个词的左端」。
