# 方向开关与周期公式

> Z 形/N 形重排:输出只按行拼接 ⇒ 每个字符的全部信息=「行号」,列坐标读出时被整个丢弃。
> 拿行号两条路:模拟走位(row 撞 0/r-1 两堵墙翻转方向)或 周期公式(行号序列周期 T=2r-2)。
> 形状是装饰,行号是本体——网格→行桶→公式,每步扔一层信息。
> 面试经典 150 题:6 · 同一子技巧的新题往对应小节追加

## 6. Z 字形变换(中等)

**题意**:把 s 按 Z 形(numRows 行,竖着下、斜着上)摆好,再从左往右逐行读出拼成新串。

**怎么想到的**:暴力=真建 r×c 网格填字再逐行扫——但输出只按行拼接,列坐标从未被用到,等于养了一整个从未读出的维度。降维三级:

1. **网格 → 行桶**:每行一个 string,字符走到哪行就追加进哪行的桶;
2. **行号 → 方向开关**:row 撞 0 或 r-1 即翻转方向,整张 Z 图压成「一个行号+一个方向比特」;
3. **开关 → 周期公式**:行号序列 0,1,…,r-1,r-2,…,1 无限循环,周期 T=2r-2(一竖 r 格+一斜 r-2 格,端点只计一次)。反过来按**输出行**拉取:行 j 每周期收两格——下行位 base+j、上行位 base+T-j,端行两位重合只收一格;写指针 k 直写输出串。

公式版是模拟的坍缩:证明了行号有闭式,就不必一格一格走——与 DP→贪心的坍缩同族;直写输出、写位互不冲突,是 42/238「输出即工作区」家族。与 14 逐列比较互为镜像:那边概念网格按列读、这边按行读,共同点是网格不落地。

**代码**(解法一:方向开关+行桶,主解;自敲版入库,变量名从自敲版):

```cpp
vector<string> rows(min(numRows, (int)s.size()));   // 先造桶:守卫路径白造一桶(坑7)
if (numRows == 1) return s;                         // Z 形状不存在(坑1)
int row = 0;
bool godown = false;                                // 初值"非向下":首格撞 0 墙翻成向下(坑3)
for (int c : s) {                                   // int 装 char:隐式转换搭桥(坑5)
    rows[row] += c;
    if (row == 0 || row == numRows - 1)             // 两堵墙:撞顶或撞底即掉头
        godown = !godown;
    row += godown ? 1 : -1;
}
string x;
for (string r : rows) x += r;                       // 按值拼桶:白拷 O(n)(坑6,绑 & 免拷)
```

解法二(周期公式,直写输出,O(1) 额外空间):

```cpp
if (numRows == 1) return s;
int n = s.size(), T = 2 * numRows - 2;
string ret(n, ' ');
int k = 0;                                      // 写指针:每源格恰属一行,k 恰走 n 步
for (int j = 0; j < numRows; j++)               // 按输出行拉取
    for (int base = 0; base + j < n; base += T) {
        ret[k++] = s[base + j];                 // 下行位:竖着下落经过 j
        if (j > 0 && j < numRows - 1 && base + T - j < n)
            ret[k++] = s[base + T - j];         // 上行位:仅中间行(端行重合,坑2)
    }
```

**坑**:
- numRows==1(0006 坑1):一横排,Z 不存在。开关版 0 与 r-1 是同一堵墙,首格翻转后 row+=1 出桶越界(n>=2 必爆);公式版 T=0,base 原地踏步,k 先写穿 ret 再死循环。同一输入两版死法不同,一行守卫两版共用。
- 端行上行位重合(0006 坑2):j=0 的上行位=下一周期下行位,j=r-1 的=本周期下行位自身。不跳过 ⇒ 端行字符收两遍、k 写穿 ret(r=3 "PAYPALISHIRING" 第 0 行变 PAAHHNN)。
- 初值与墙要配套(0006 坑3):两头墙+初值 false 才自洽;初值 true 第 2 格 row=-1,只判底墙配 false 第 2 格 -1、配 true 撑到第一次回顶后 -1。0 墙兼任「起步」与「回顶」两职,漏判必在顶上出界。
- numRows>=n(未爆,0006 坑4):一竖列答案=s,两版免守卫天然正确(走不到回头墙/上行位全越界被跳过),早退守卫只是省一趟。
- int 循环变量(未爆,0006 坑5,自敲):范围 for 变量类型不必精确匹配——int 装得下 char 全部值,`+=` 时 int→char 收窄挑 operator+=(char),全程静默、char→int→char 往返保真;同族 for(double d:v) 装 vector<int> 才开始无声截尾。
- 按值拼桶(未爆,0006 坑6,自敲):for(string r:rows) 每桶整串拷贝再拼接,白拷 O(n);绑引用免拷——只读重元素也付拷贝税。
- 守卫后置(未爆,0006 坑7,自敲):桶构造在 r==1 守卫前,守卫路径白造一桶;守卫前置连桶都不用起。

**复杂度对比**:
- 方向开关+行桶:O(n) 时间、O(n) 空间(桶内字符共 n 个)
- 周期公式直写:O(n) 时间、O(1) 额外空间(输出即工作区;每源格恰属一行,写位两两不同)
- 暴力网格:填 O(n)、逐行扫 O(r·c),c≈(r-1)·n/T 为 n/2 量级 ⇒ O(n·r) 空间

## 原理

行号序列为什么周期 T=2r-2:Z 形一节=先竖着走 r 格(顶到底),再斜着回升 r-2 格(只经过中间行,端点与下一节共享)⇒ 一节共 2r-2 个字符,行号走 0,1,…,r-1,r-2,…,1 后回到 0(下一节起点)。i 的落行:k=i mod T,k<r ⇒ 行 k(竖段),k>=r ⇒ 行 T-k(斜段)。「输出只依赖行号」是全部省力的根据:列在读出时被丢弃,养着它只为「看形状」——形状是装饰,行号是本体。三级降维(网格→行桶→公式)每一步扔掉一层没人读的信息;与 14 同一条守则的正反面:那边按列读、不建网格,这边按行读、连行都不真摆、只记账。公式版按输出行拉取时,每个源下标恰属一行(竖段/斜段互不重叠、端点只计一次),所以写指针 k 恰走 n 步、不重不漏——这是「输出即工作区」能安全落地的先决条件(对照 88 逆序写:那边要防覆盖,这边写位天生互异)。
