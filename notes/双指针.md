## 逆序双指针 —— 88. 合并两个有序数组(简单)

**题意**:nums1 尾部有 n 个空位,把有序的 nums2 归并进去。

**为什么从后往前**:空位在尾部,从后往前每次取两边**较大**者填入,写入位置 `k = i + j + 1` 恒大于 i,永远不会覆盖 nums1 未处理的元素 → 不用开额外数组,O(m+n) 原地完成。

```cpp
int i = m - 1;         // nums1 有效部分末尾
int j = n - 1;         // nums2 末尾
int k = m + n - 1;     // 写入位置
while (i >= 0 && j >= 0) {          // 注意 &&:比较需要两边都有元素
    if (nums1[i] > nums2[j]) nums1[k--] = nums1[i--];
    else                    nums1[k--] = nums2[j--];
}
while (j >= 0) nums1[k--] = nums2[j--];   // 只需善后 nums2!
```

**为什么 nums1 剩的不用管**:循环结束时若 nums1 有剩余,说明它们都比已填入的小,且位置天然正确;nums2 剩的还没进数组,必须搬。

**精简变体**:主循环只判 `while (j >= 0)`,判断写 `if (i >= 0 && nums1[i] > nums2[j])` —— 把「i 耗尽就搬 nums2」合进 else,连善后循环都省了。

**复杂度对比**:
- 拷贝 + sort:O((m+n)·log(m+n)),没利用「两个数组各自有序」
- 逆序双指针:O(m+n) 时间、O(1) 空间 ← 进阶要求

## 快慢指针 —— 27. 移除元素(简单)

**核心**:原地「删除」= 把 ≠ val 的元素抄到前面,返回个数 k,后面留什么无所谓(评测只看前 k 个再排序)。

```
[ 保留区(已确认≠val) | 未扫描区 | 不关心区 ]
        ↑slow              ↑fast
```

- `fast` 读指针扫全数组;`slow` 写指针只在 `nums[fast] != val` 时接收并前进;
- 安全性:**读永远在写前面**(fast ≥ slow 恒成立),被覆盖的都是考察过的废数据。

下标版:

```cpp
int slow = 0;
for (int fast = 0; fast < (int)nums.size(); fast++) {
    if (nums[fast] != val) nums[slow++] = nums[fast];
}
return slow;
```

裸指针版(下标版的等价记法):

```cpp
int* end = nums.data() + nums.size();   // 末尾哨兵
int* i = nums.data();                   // 写指针
for (int* j = nums.data(); j < end; j++) {
    if (*j != val) { *i = *j; i++; }
}
return i - nums.data();   // 指针之差 = 保留个数
```

两版等价的原理:`nums[fast]` ≡ `*(nums.data() + fast)`。

**进阶(未做)**:val 很少时用「换」代替「抄」——等于 val 的位置和末尾元素 swap 后右边界收缩,换来的元素原地再查(fast 不前进)。写入次数从 O(n) 降到 O(删除数)。

**反面教材**:`nums.erase(...)` 逐个删是 O(n²),且绕开了考点,面试不认。
