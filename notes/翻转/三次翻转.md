# 三次翻转

> 换位靠「整体翻一次定段序 + 每段翻回定段内」:右移 k 是两段换位 [A|B] → [B|A](189),反转单词是任意段换位(151),都 O(1) 空间。
> 面试经典 150 题:189 / 151 · 同一子技巧的新题往对应小节追加

## 框架总览

记 A = 前 n−k 个、B = 尾部 k 个,右移 k 的目标就是 [A|B] → [B|A]:

```cpp
k %= n;                              // k 可远大于 n,先取模
reverse(v.begin(), v.end());         // ① 整体翻:[A|B] → [rev(B)|rev(A)]
reverse(v.begin(), v.begin() + k);   // ② 前 k 个翻回 → [B|rev(A)]
reverse(v.begin() + k, v.end());     // ③ 剩余翻回 → [B|A]
```

②③ 作用于不相交区间,先后无所谓;等价变体「先翻前 n−k、再翻后 k、最后整体翻」同样得 [B|A]。循环左移 k ⇔ 右移 n−k,同一框架。

「三次」不是定数,骨架是**整体一次 + 每段一次**:段数 = 2 时数出来恰好三次(189);
151 反转单词序是任意段版——k 个词整体翻一次,再逐词翻回,共 1+k 次。各段区间互不
相交,先后无所谓;段内字母被翻两次 = 没翻(对合),段序只被整体翻动过一次 = 恰好倒转。

## 189. 轮转数组(中等)

**题意**:nums 向右轮转 k 位;进阶要求 O(1) 空间原地。

**怎么想到**:右移 k = 尾部 k 个搬去开头 = 两段换位。两段不等长,逐个搬会互相覆盖、开新数组又不满足 O(1);而「翻转」是 O(1) 空间里现成的整体搬移操作——连翻三次凑出换位。

**箭头图**(评论区 1.4K 赞,看过就忘不掉):nums = `"----->-->"`,k = 3

```text
整体翻       "<--<-----"    两段各自就位,连箭头方向都翻过来了
前 3 个翻回   "--><-----"
剩余翻回      "-->----->"    尾部的 --> 已搬到头部,即答案
```

**代码**:

```cpp
void rotate(vector<int>& nums, int k) {
    int n = nums.size();
    k %= n;
    reverse(nums.begin(), nums.end());
    reverse(nums.begin(), nums.begin() + k);
    reverse(nums.begin() + k, nums.end());
}
```

**手写翻转**(吃透原理用;`<algorithm>` 的 reverse 就是它,对撞双指针交换):

```cpp
void myReverse(vector<int>& v, int l, int r) {   // 翻转 [l, r]
    while (l < r) swap(v[l++], v[r--]);           // 对撞相遇即停,单元素自然不动
}
```

**坑**:
- k ≤ 10⁵ 而 n 可以是 1:不先 `k %= n`,翻转区间长度按 k 算,越界/结果全错。取模必须第一步做。
- 取模后 k = 0(含 n = 1):三个 reverse 全空转,无需特判。

## 151. 反转字符串中的单词(中等)

**题意**:返回单词顺序颠倒、词间单空格、无前后导空格的结果;进阶要求 O(1) 空间原地解。

**怎么想到**:题面是两层结构——「词的序列」要倒,「词内字母」不许动。整体翻一次两层全翻(词序立刻到位,字母跟着倒);再逐词翻回,只回滚字母层。这正是上面骨架的任意段版,唯一多的工序是**先压实**:多余空格不除,词边界就定不干净(逐词翻的 start/i 全靠单空格分词)。

**三步**(主文件 `面试经典150题/0151-*.cpp` 解法二,完整代码在那里):

```cpp
// ① 快慢指针压实:非空格必留,空格仅当保留区末尾不是空格才留(判据详解见 双指针/快慢指针.md)
//    收尾:尾部恰好多留的一格 slow--;s.resize(slow) 砍掉废尾
reverse(s.begin(), s.end());                 // ② 整体翻:词序倒转,词内字母跟着倒
for (int i = 0, start = 0; i <= n; i++)      // ③ 逐词翻回:字母复原,词序不动
    if (i == n || s[i] == ' ')  { reverse(s.begin()+start, s.begin()+i); start = i+1; }
```

**坑**:
- 只整体翻一次:s 变 `"eulb si yks eht"`——两层全翻,题目只要词序层。
- 词后统一补空格/词间留空格 ⇒ 末尾必多一格:压实收尾 slow-- + resize 一刀;「统一动作+末尾一刀」是哑结点家族的手法。
- 逐词翻的收尾哨兵 i==n **只当信号,不当值**:`i == n || s[i]==' '` 左项短路挡住右项的 s[n] 越界读——58 的 `i>=0 && s[i]` 同一招,挡的方向相反;坑总集「哨兵用<=」的病根是解引用哨兵,不是 <= 本身。

**直球解**(O(n) 空间):58 倒序扫描的「不停版」,从右往左收词天然倒序,见 `字符串/倒序扫描.md` 的 151 节——不追求 O(1) 时这是最先该想到的。

## 原理

翻转是对合:rev(rev(X)) = X。整体翻完成「换位」但两段内部都反序;分段翻恰好把各自翻回去。每个元素恰好被换 2 次(整体 1 次 + 所在段 1 次),共 n 次交换 = O(n)。151 是任意段版的使用证书:整体翻负责段序层、分段翻负责段内层,两层各翻各的,每元素仍恰好被换 2 次。
