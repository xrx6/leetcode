# 贪心分行与余数均摊

> 排版/装箱类两步走:先把元素贪心装进「行/桶」,再把余量在槽位间均摊。
> 判据最常漏的账:元素之间有隔断(空格),新元素入场费 = 隔断 + 自身长度。
> 均摊唯一公式:整除发底薪,余数从左发——这是「尽量均匀+左多右少」的唯一解。
> 面试经典 150 题:68 · 同一子技巧的新题往对应小节追加

## 68. 文本左右对齐(困难)

**题意**:单词数组 words 与行宽 maxWidth,每行恰 maxWidth 字符:贪心装行(尽可能多装),行内空格尽量均匀且左多右少;末行左对齐词间不插额外空格。

**怎么想到的**:拆成互不相干的两件事——

1. **哪些词同行**(题面点名贪心):判据别漏空格账。len 记「单词总长+词间最小空格」,新词 w 想进场,入场费 = 1 格隔断 + 词长,`len + 1 + w <= maxWidth` 才收。
2. **空格怎么摆**:先认行型再动格。行只有三种:末行(`j==n`)与单词成行(`wc==1`,0 个间隙无处塞格)都走**左对齐**——词间恰 1 格,行尾补满;普通行走**两端对齐**——`totalSpaces = maxWidth - 单词总长`,`base = 总/隙数`,`extra = 总%隙数`,前 extra 个隙各多 1 格(「左多右少」= 余数从左发)。

守恒式:单词总长 + 全部间隙格数 = maxWidth,每行拼完拿它验收。

**代码**(标准解,O(总字符)/O(答案)):

```cpp
for (int i = 0; i < n; ) {
    int j = i + 1, len = words[i].size();          // len=单词总长+词间最小空格
    while (j < n && len + 1 + words[j].size() <= maxWidth)
        len += 1 + words[j++].size();              // 新词入场费:1 格隔断+词长
    int wc = j - i;
    if (j == n || wc == 1) {                       // 末行/单词行:左对齐
        for (int k = i; k < j; k++)
            line += words[k] + (k == j - 1 ? "" : " ");
        line.append(maxWidth - line.size(), ' ');
    } else {                                       // 普通行:余数均摊
        int totalSpaces = maxWidth - (len - (wc - 1));   // len 扣掉已垫的最小格
        int base = totalSpaces / (wc - 1), extra = totalSpaces % (wc - 1);
        for (int k = i; k < j; k++) {
            line += words[k];
            if (k < j - 1) line.append(base + ((k - i) < extra), ' ');
        }                                          // 行末词后面不贴
    }
    ans.push_back(line); i = j;
}
```

讲解沉淀(2026-11-01 一步一步问答回放):

- **判据手算**(示例 1,maxWidth=16):第 1 行 len:4(This)→ 4+1+2=7 收 is → 7+1+2=10 收 an → 10+1+7=18 爆,行 1=[This,is,an];第 2 行 7→10→15 收 of,text;15+1+14=30 爆。+1 就是隔断账,漏了它行必超装。
- **余数现场**(第 2 行 [example,of,text]):单词总长 15-2=13,空格 3,gaps=2,base=1,extra=1 → 隙 2、1:`example──2──of─1──text` = 7+2+2+1+4=16 ✓。第 1 行:总 8,gaps 2,base=4,extra=0,两隙各 4。
- **沉淀两句**:新词入场费=1 格隔断+词长(标准版 len 含最小空格、判据 +1;修错版 cur 只含词长、判据 +cnt——同一笔账两种记法);**轮流贴格 ≡ base+extra**——从最左隙起一轮贴 1 格,⌊总/隙⌋ 整轮后剩下的恰落在最左几隙,一轮一格从左到右天然「左多右少、差不过 1」。
- **修错版对照**(保留首敲骨架):贴在词尾=给它和右边词的间隙,行末词右边没词一格不给(回绕范围是前 gaps 个词);`while(count[j]--)` 拼完 start 恰好跨过本行,循环外别再 `++`。

**坑**(全文九条见 0068 头部,此处记主题层):

- 首句 `maxWidth=0` 毁参数(68 坑1):行宽是题面给的、不是让你算的;最小反例单词输入 ["a"] 返回空——两个循环都不跑,连 UB 都不经过。参数先当只读。
- 空 vector 下标写 UB(68 坑2,45/238/68 三进宫):`neww[j]=xxx` 误当能像 push_back 长元素;operator[] 不检查不扩容。
- 贪心判据漏隔断账(68 坑3):只累加词长不算空格,行必超装。
- 丢词三处(68 坑4):`i<size()-1` 漏末词;`start++` 在 start 已==i 时跳词;循环结束最后一组没收尾 flush。
- 行长拿错对象(68 坑5)/轮流贴格三错(68 坑6:c>=0 多一格、回绕含行末词、单词行未特判)/游标多 `++`(68 坑7)/分支该按行型不按行宽(68 坑8)。
- 坏味道(68 坑9):连续行号做键用 vector 不用 unordered_map;数据结构语义(存词还是存行)先定死再动手。

**复杂度**:时间 O(总字符)——每词进出分组各一遍,每行拼接 O(maxWidth);空间 O(答案)。基线:按最小空格 join 后逐行手补,也是 O(n),考的是判据与均摊的算术,不是数据结构。

## 原理

**贪心装行为什么合法**:题面规定贪心(「尽可能多地放」),无需证明最优;但可看清它不亏——多装一词只多花 1 格隔断,后面的行只会更松,行数取到下界。

**余数均摊的唯一性**:设空格总数 S 分给 g 个隙,任何「尽量均匀」的分配形如每隙 q 或 q+1 格(S=q·g+r,0≤r<g);「左多右少」钉死方向:前 r 个隙拿 q+1、其余拿 q。两种实现同一件事:公式法一次算清(除法+取余);轮流法(一轮给每隙 1 格,从左到右)整轮 ⌊S/g⌋ 遍后剩 r 格自然落在最左 r 个隙。隙差≤1 ⟺ 均匀,左=前隙 ⟺ 左多右少,题面两个条件合起来唯一确定这张分配表——所以不存在「另一种对的空格摆法」。
