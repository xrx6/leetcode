# 失配回退与失配表

> 子串查找:失配后,下一个候选起点可能藏在「已比过的窗口」内部——两条正路:朴素肯回头(起点+1 重比),KMP 不回头带账本(π 表=最长相等前后缀,失配跳 π[s-1] 续比当前字符)。
> 单指针失配 s=0 硬归零 = 整段丢窗口,是最自然的错法:方向对了一半(带已配长省重复比较),丢的那一半正是本题全部难点。
> 面试经典 150 题:28 · 同一子技巧的新题往对应小节追加

## 28. 找出字符串中第一个匹配项的下标(简单)

**题意**:在 haystack 里找 needle 第一个出现的下标,找不到返回 -1。

**怎么想到的**:暴力=每个起点整段重比 O(n·m)。省力的钥匙在失配瞬间:已配过的 s 格窗口 [i-s, i-1] 与 needle[0..s-1] 相等,这是免费信息。两条路:

1. **朴素,肯回头**:窗口不记账,失配后起点 start+1,i 退回去重比。简单,但每个新起点几乎从头比;
2. **KMP,不回头带账本**:窗口内起点 p∈(i-s, i) 还有救 ⇔ haystack[p..i-1]=needle 前缀 ⇔(窗口=needle 前缀)窗口末 i-p 格恰是 needle 同长前缀,即 needle[0..s-1] 的一个**相等前后缀**。能救的最早 p 对应**最长**相等前后缀 π[s-1] ⇒ 失配时 s=π[s-1],当前字符再比;跳过的更早起点需要更长的相等前后缀,不存在 ⇒ 必败(「最长」二字就是下界证书)。

失配去向只依赖 needle、与 haystack 无关 ⇒ 预处理成 π 表一次算清(压表),主匹配零回退 O(n);造表=needle 对自己跑同一个匹配循环(自己找自己),循环形状与主匹配完全相同。

**代码**(KMP,主解):

```cpp
vector<int> pi(m, 0);                          // pi[j]:needle[0..j] 最长相等真前后缀
int j = 0;
for (int i = 1; i < m; i++) {                  // 造表:自己找自己,形状同主匹配
    while (j > 0 && needle[i] != needle[j]) j = pi[j - 1];
    if (needle[i] == needle[j]) j++;
    pi[i] = j;
}
j = 0;                                         // 已配长:失配不归零,跳 pi[j-1] 续比
for (int i = 0; i < n; i++) {
    while (j > 0 && haystack[i] != needle[j]) j = pi[j - 1];
    if (haystack[i] == needle[j]) j++;
    if (j == m) return i - m + 1;              // 找到即退,迟退下一轮 needle[j] 越界
}
return -1;
```

朴素版(肯回头,先会这个):

```cpp
for (int start = 0; start + m <= n; start++) { // 剩余不足 m 格免比
    int j = 0;
    while (j < m && haystack[start + j] == needle[j]) j++;
    if (j == m) return start;
}
return -1;
```

mississippi/issip 对照现场:原解 i=5 's'≠ne[4]'p' 时 s:4→0,窗口 [1,4]="issi" 全丢,终局 -1;KMP 同一位置 s:4→π[3]=1("issi" 的最长相等前后缀是 "i"),i=5 's'==ne[1] 续配,i=6,7,8 一路配到 'p',return 8-4=4——同一失配点,归零丢棋,跳表续命。

**坑**:
- 失配归零丢窗口(28 坑1,自敲 WA):两层——①失配字符没重比 needle[0] 就被消费("aab"/"ab" 输 -1 应 1);②补上重比仍不够,新起点可在窗口内部("mississippi"/"issip" 失败窗口 [1,4]="issi",正解起点 4 在窗口内,应 4 得 -1;补丁版 "aaab"/"aab" 仍错)。窗口信息要么回头重拿要么记账,单指针归零两头都不占。m==1 无状态可丢恒对、给定示例无重叠结构 → 70/86 巧合通过。
- 朴素起点上界 start+m<=n(28 坑2):剩余不足 m 格免比;m>n 循环不进自动 -1,不用守卫。
- KMP 找到即 return(28 坑3):s 到 m 不早退,下一轮 needle[s] 越界。
- find 彩蛋(28 坑4,未爆):npos=SIZE_MAX 截断到 int 恰 -1,歪打正着(实现定义→C++20 定死补码),正路写显式三目。
- needle.size()-1 下溢(28 坑5,未爆):m=0 时 size_t 域算成 SIZE_MAX,条件恒真再 needle[0] 越界 UB,本题 m>=1 挡住。

**复杂度对比**:
- 朴素:O(n·m) 时间、O(1) 空间(n,m≤1e4 最坏 1e8 次字符比较,放行但贴上限)
- KMP:O(n+m) 时间、O(m) 空间
- 库函数 find 一行:O(n·m) 量级(实现内部有优化),面试当「知道有轮子」的答案

## 原理

π[s-1] 不多不少的证明:失配时窗口=needle[0..s-1] 已知;窗口内起点 p 有救 ⇔ 窗口末 i-p 格=needle 同长前缀 ⇔ needle[0..s-1] 有长 i-p 的相等前后缀。π[s-1] 是最长者,给出最早的活口 p*=i-π[s-1];比 p* 更早的起点要求更长相等前后缀,与「最长」矛盾 ⇒ 必败,所以失配跳 π 恰好不漏不重。为什么与 haystack 无关:判断里 haystack 的戏份已全部由窗口(=needle 前缀)代演。主匹配零回退的代价是造表 O(m):把每个失配位置的唯一去向预压缩进一张表——与 12 罗马面额表同族(压表:运行期决策提到预处理期一次算清)。KMP 与朴素的关系不是「聪明版暴力」,是同一免费信息的两种处置:扔掉(回头重拿)或记账(跳表续拿)。
