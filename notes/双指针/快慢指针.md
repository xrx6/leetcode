# 快慢指针

> 同向双指针:fast 负责读,slow 负责写,把该保留的元素「压实」到数组前部。
> 面试经典 150 题:27 / 26 / 80 · 同一子技巧的新题往对应小节追加

## 框架总览(先看这节)

```
[ 保留区(已定稿) | fast 未扫区 | 废数据区 ]
        ↑slow 写入位置          ↑fast 只往右走
```

- fast 读指针扫全数组,每个元素只读一次,只做「收 / 跳」二选一;
- **覆盖安全**:slow ≤ fast 恒成立(写指针追不上读指针),盖掉的都在 fast 脚印后面,是考察过的废数据 ⇒ 原地完成,O(1) 空间;
- 题目只变三个自由度:**留什么**(条件)、**怎么写**(slow 语义)、**报什么**(返回值)。

| 题 | 保留规则 | 收的条件 | 写入 | slow 起步 | 返回 |
|---|---|---|---|---|---|
| 27 移除元素 | ≠ val 的全留 | `nums[fast] != val` | `nums[slow++]` | 0 | slow |
| 26 去重 I | 每值留 1 份 | `nums[fast] != nums[slow-1]` | `nums[slow++]` | 1 | slow |
| 80 去重 II | 每值留 2 份 | `nums[fast] != nums[slow-2]` | `nums[slow++]` | 2 | slow |

**统一公式:允许留 k 份 ⇔ 和倒数第 k 个保留值比 ⇔ slow 从 k 起步。**骨架永远不变,换个参数就是新题。

## 27. 移除元素(简单)—— 裸模板

**题意**:原地删掉所有等于 val 的元素,返回保留个数 k。

条件独立于数组内容(只看 `!= val`),slow = 下一个写入位置 = 保留个数,先写后走:

```cpp
int slow = 0;
for (int fast = 0; fast < (int)nums.size(); fast++)
    if (nums[fast] != val) nums[slow++] = nums[fast];
return slow;
```

裸指针版(等价记法,练指针算术;原理:`nums[fast]` ≡ `*(nums.data() + fast)`):

```cpp
int* end = nums.data() + nums.size();   // 末尾哨兵:能比较,不能解引用
int* i = nums.data();                   // 写指针
for (int* j = nums.data(); j < end; j++)
    if (*j != val) *i++ = *j;
return i - nums.data();                 // 指针之差 = 保留个数
```

**进阶(未做)**:val 很少时用「换」代替「抄」——等于 val 的位置和末尾元素 swap 后右边界收缩,换来的元素原地再查(fast 不前进)。写入次数从 O(n) 降到 O(删除数)。

**反面教材**:`nums.erase(...)` 逐个删是 O(n²),且绕开考点,面试不认。

## 26. 删除有序数组中的重复项(简单)—— 条件第一次依赖保留区

**题意**:非严格递增数组原地去重,每个值留 1 份,返回 k。

**怎么想到的**:有序 ⇒ 重复必相邻 ⇒ 副本挤在一起,fast 踩过去就再也不会遇到 ⇒ 「留不留」不用看全部历史,只和**最后一个已保留的值**比一次。

个数版(与框架表一致,先写后走):

```cpp
int slow = 1;                                // 首元素天然保留
for (int fast = 1; fast < (int)nums.size(); fast++)
    if (nums[fast] != nums[slow - 1])        // 和倒数第 1 个保留值比
        nums[slow++] = nums[fast];
return slow;
```

下标版(slow 直接指着参照物,先走后写):

```cpp
int slow = 0;                                // 最后一个保留元素的下标
for (int fast = 1; fast < (int)nums.size(); fast++)
    if (nums[fast] != nums[slow])
        nums[++slow] = nums[fast];
return slow + 1;                             // 下标 + 1 = 个数
```

**坑**:
- 比较对象必须取自保留区,不能写 `nums[fast-1]`——fast 前面的格子可能已被覆盖成新值。反例:`[0,0,0,1]`,fast=3 时 nums[2] 还是旧值 0,误判成新值多写一次。
- fast 从 1 起(首元素天然保留);LeetCode 约定 n ≥ 1,个数版不用判空。
- 一行流 `nums.erase(std::unique(...), nums.end())` 是反面教材:`std::unique` 内部就是这套快慢指针,面试考手写。

状态:看过提示(卡进 while+for 嵌套循环后,回到 27 套路)。

## 80. 删除有序数组中的重复项 II(中等)—— 泛化:留两份

**题意**:同 26,每个值最多留 2 份。

**弯路复盘(自创「间隙跳坑法」,WA on `[0,0,1,1,1,1,2,3,3]`)**:
用 `fast-slow>=2` 当「当前值已留满两份」的信号,命中就 `slow+=2` 占两坑、只写一坑,赌被跳过的坑里恰好留着正确的旧值。错在:
1. **间隙大小 ≠ 保留份数**:跳过的重复会把间隙撑大,与「这个值出现过几次」无关(用例里 fast=6 时间隙为 4,可 2 是全新值);
2. **占坑不填**:前一个值只留一份时(用例里的 2),被跳的坑就是垃圾(fast=7 时 nums[5] 留下旧值 1)。

返回值碰巧对、内容错 ⇒ 报解答错误。教训:**份数是状态,要么真记下来,要么用比较对象隐式表达,不能拿下标差去猜。**

**正确解法**(= 框架表 k=2 那行):

```cpp
if (nums.size() <= 2) return nums.size();   // 前 2 个无条件保留,先兜住
int slow = 2;
for (int fast = 2; fast < (int)nums.size(); fast++)
    if (nums[fast] != nums[slow - 2])       // 倒数第 2 个保留值
        nums[slow++] = nums[fast];
return slow;
```

**为什么只查倒数第二格就够**:保留区按序抄自有序数组 ⇒ 保留区也有序 ⇒ 同值副本必是末尾连续一段(fast 读到的值 ≥ 保留区一切,重复只可能堆在尾部)。末尾两格只有两种长相:
- 长相 A `[...x, x]`:新数 == 倒数第二个 ⇒ 有序性夹得最后一格也相等 ⇒ 末尾已两份 ⇒ 拒
- 长相 B `[...a, b]`(a≠b):末尾各值至多一份,再收顶多第二份 ⇒ 收

新数若和更老的数相等,有序性逼着中间全相等 ⇒ 末尾必是一串它 ⇒ 末尾一查全覆盖,前面藏不住重复。**份数不用数,比较对象降 k 位就是查份数。**

**n≤2 特判**:slow 从 2 起步,数组不足 2 个会越界;26 个数版从 1 起步靠 n≥1 约定兜底,80 只能靠特判。
